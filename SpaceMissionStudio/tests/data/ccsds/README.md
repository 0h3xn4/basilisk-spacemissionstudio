# CCSDS example messages

KVN examples copied from CCSDS 502.0-B-3 (Orbit Data Messages, Blue Book,
April 2023), Annex G (informative): figures G-1 to G-4 (OPM), G-7 to G-9
(OMM) and G-11 to G-13 (OEM). The "< intervening data records omitted here >"
placeholder lines of the OEM figures are removed; nothing else is changed.
Used by `tests/test_ccsds_odm.py`.
